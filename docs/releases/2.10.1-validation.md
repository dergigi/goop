# Goop 2.10.1 release validation

## Scope

Message-loading responsiveness, background local-state persistence, reaction deduplication, and connection-status layout and signer actions.

## Checks before packaging

- 187 local library and UI regression tests passed; one crash subprocess fixture is intentionally ignored outside its parent test.
- Six release-policy tests and six mocked Linux installer tests passed.
- Optimized macOS build from the release source passed with `gpui_macos/runtime_shaders`.
- Test coverage includes ordered/coalesced persistence, failure retries, flush-on-quit behavior, reaction delivery deduplication, room loading, and stable history-counter layout in narrow panes.
- Initial local test compilation exhausted disk space. Removing regenerable Goop debug incremental cache allowed the complete suite to pass.
- Release source: `cddf4bc32229ebcb8e6d5f130467a8e89fb206b1` (`v2.10.1`).

## Release checks

- Published [v2.10.1](https://github.com/dergigi/goop/releases/tag/v2.10.1); public latest and its checksum download resolve to this release.
- [Platform CI](https://github.com/dergigi/goop/actions/runs/35173928867) passed on Linux, macOS, and Windows, including shared UI regressions and Linux credential fallback checks.
- [All six installer builds](https://github.com/dergigi/goop/actions/runs/35173945265) passed. All ten installers passed SHA-256 verification; all eleven assets matched GitHub digests and sizes.
- Both Windows executables have GUI subsystem type 2 and all six icon images. Their architectures and package versions match the release.
- Both macOS bundles passed version, identity, architecture, camera permission metadata, and strict signature checks. Linux ELF architectures and Snap manifests match; both Flatpaks contain the expected runtime, Flathub runtime repository, and Secret Service permission.
- Exactly one updater installer exists for each OS/architecture.
- Installed and opened the Apple Silicon release build in `/Applications/Goop.app`, preserving user data. Its disk image matches the published asset byte for byte, and its installed executable matches the verified release bundle.
- [Homebrew update](https://github.com/dergigi/homebrew-goop/actions/runs/35176006282) passed; the cask version and both macOS checksums match the release.
- Landing-page production build and Vercel deployment passed for commit `2b86b42`. The live site shows 2.10.1, includes all release asset links and the Goop profile link, and serves `install.sh` byte for byte from the repository installer.

## Limits

macOS bundles are ad-hoc signed, not notarized; Windows installers have no developer certificate. Full interactive Windows/Linux UI testing has not been performed. User testing covered the preceding local UI builds. This release reduces known sources of repeated and blocking work but does not claim to eliminate every startup stall. Forced termination or persistent storage failure can still lose pending local-state writes. Existing cross-client interoperability and large-history performance gaps in the DM validation checklist remain open.
