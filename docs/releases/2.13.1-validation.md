# Goop 2.13.1 release validation

## Scope

- Connect inbox relays before installing the live NIP-17 subscription.
- Reuse a successfully persisted signer connection key within the app session and serialize concurrent pairing requests.
- No credential-store migration or Keychain permission changes. Update-time Keychain prompts from ad-hoc signing remain a known limitation tracked in #6; #3 is not claimed resolved.

## Source validation

- PR #5: CodeRabbit's caller-coverage finding addressed by extracting the production background history flow and exercising it with a published inbox list and a live peer reply after the history scan. Original helper-level regression retained.
- 78 chat tests and 20 state tests passed.
- Removing the history flow's live-subscription call causes the caller regression to time out; restoring it passes. Removing relay connection setup causes the helper regression to time out; restoring it passes.
- Connection-key tests cover overlapping/later requests sharing one load and failure followed by successful retry.
- Optimized macOS desktop build passed with runtime shaders. Local Clippy completed; warnings were confined to existing, unchanged code.
- Release-policy and mocked Unix installer checks passed (6 and 11 tests).
- Test builds used the release profile with LTO disabled and 16 codegen units to reuse local artifacts.

## Limits

- Local-relay tests cover receive setup and real encrypted events, not a fresh interactive external-signer test with the original reporter.
- Existing broad interoperability/performance/GUI validation gaps in the DM checklist remain. No new feature-parity or startup-performance claim is made.
- macOS installers remain ad-hoc signed and Windows installers unsigned. Stable Developer ID signing is deferred.
