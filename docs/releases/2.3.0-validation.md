# Goop 2.3.0 release validation

Application source: `v2.3.0`, commit `bac5450679e7edbb1d076b6db219dc396162d627`.

## Checks

- 91 local regression tests and 6 release-tooling tests passed.
- [Cross-platform CI](https://github.com/dergigi/goop/actions/runs/34913016242) passed on macOS, Windows, and Linux.
- [Installer workflow](https://github.com/dergigi/goop/actions/runs/34913016572) passed on all six OS/architecture targets.
- All ten installers matched SHA256SUMS. All eleven uploaded assets matched GitHub's sizes and SHA-256 digests.
- Windows executable architectures and package versions, Linux tarball executable architectures and Snap versions/architectures, and both macOS bundle versions, identities, architectures, and strict signatures were verified.
- Exactly one updater installer matches each target OS/architecture.
- Published as latest stable; the public checksum download matches the validated manifest.
- An optimized local v2.3.0 build was installed and launched successfully on Apple Silicon macOS.

## Limits

Nospeak archive compatibility was checked against source and local relay fixtures; live cross-client testing remains pending. Checkmarks indicate relay acknowledgements, not device delivery or read receipts. Group Leave is local to this device and cannot prevent other clients from sending messages.

macOS bundles are ad-hoc signed, not notarized. Windows installers have no developer certificate. Full interactive testing on all platforms remains incomplete.
