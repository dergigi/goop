# Goop 2.5.0 release validation

Application source: `v2.5.0`, commit `4730cde31c025971a95547f5e5bc991982a644f1`.

## Checks

- 79 local chat, composer, and workspace regression tests and 6 release-tooling tests passed. The subsequent Welcome layout change passed compilation and the final cross-platform CI suite.
- [Cross-platform CI](https://github.com/dergigi/goop/actions/runs/34938373823) passed on macOS, Windows, and Linux at the release commit.
- [Installer workflow](https://github.com/dergigi/goop/actions/runs/34938376665) passed on all six OS/architecture targets at the release commit.
- All ten installers matched SHA256SUMS. All eleven uploaded assets matched GitHub's sizes and SHA-256 digests.
- Windows executable architectures and package versions, Linux tarball executable architectures and Snap versions/architectures, and both macOS bundle versions, identities, architectures, and strict signatures were verified.
- Exactly one updater installer matches each target OS/architecture.
- Published as latest stable; the public checksum download matches the validated manifest.
- An optimized local v2.5.0 build from the final release source was installed and launched on Apple Silicon macOS. All executable sections matched the build after signing; the installed version and strict bundle signature were checked.
- Read-state regressions cover batch marking, isolation from other chats and future messages, manual-unread persistence, legacy data, and Note to self.

## Scope and limits

This release adds chat read controls, a rounded composer, profile navigation and action buttons, a dedicated public-key copy row, and short-window layout fixes. Read state remains local to this device and publishes no read receipts.

Profile Search uses the existing find-in-chat implementation after opening the matching conversation. Welcome centers when its content fits and scrolls when it cannot. Draft growth is limited by window height, with longer text scrolling inside the editor.

Full interactive testing of menus, focus, resizing, and layout on every platform remains incomplete. macOS bundles are ad-hoc signed, not notarized; Windows installers have no developer certificate.
