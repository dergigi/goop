# Goop 2.13.0 release validation

Release source: `ed3df7743c5458a4cb049f90e7f765678001f114` (`v2.13.0`).

## Scope and interactive testing

- Encrypted NIP-37 draft sync for NIP-17 messages, including reply targets, with the account's kind-10013 private-storage relay list.
- Private-storage relay management, Cmd/Ctrl+Shift+R, and icons for account-menu navigation.
- Gigi tested draft synchronization in both directions between Goop and Amethyst and reported success before authorizing the release.
- Installed optimized development builds on the development Mac for interactive testing, preserving the existing data directory. The final pre-release install was build `20260918.183816`.

## Local validation

- Chat: 76 tests passed, including encrypted relay exchange, private relay isolation, signer refusal, restart, tombstones, and protection of unsynced local edits.
- Chat UI: 31 tests passed, including remote-refresh protection while typing and prevention of stale startup restoration.
- State: 18 tests passed, including encrypted private-storage relay lists, account validation, and empty-list handling.
- Workspace: 39 tests passed.
- Release policy: 6 tests passed. Mocked Unix installer: 11 tests passed.
- Optimized desktop build and compile check passed.

## Limits

- Draft sync uses configured private-storage relays. With an empty list, drafts remain local.
- One visible draft per conversation; unsynced local edits take priority over incoming changes. Attachment uploads and NIP-37 revision history are outside this release's sync scope.
- Local persistence does not guarantee survival of every abrupt power loss or disk failure.
- The existing unsigned/ad-hoc packaging limitations remain; this release adds no Developer ID signing or notarization.
