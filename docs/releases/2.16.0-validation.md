# Goop 2.16.0 validation

## Scope

Publish the merged ants.sh profile-link feature from PR #14. The message context menu now offers ants.sh alongside njump.to. The profile pane uses a verified NIP-05 address when available and otherwise falls back to npub. The message menu always uses the author's npub because chat metadata has not undergone that verification.

## Review and limits

PR #14's original platform checks and CodeRabbit check passed without review findings. Release preparation corrected the message-menu path so an unverified NIP-05 claim cannot point to another identity. This is an external-link UI change; message transport, database schema, and signer behavior are unchanged. No additional cross-client interoperability or manual GUI coverage is claimed. macOS remains ad-hoc signed; stable Developer ID signing is tracked in #6.
