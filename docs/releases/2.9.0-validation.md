# Goop 2.9.0 release validation

## Scope

Full Unicode emoji pickers for messages and reactions; quieter idle update status; Linux credential storage through upstream oo7 0.7.0-alpha with Secret Service fallback; Flatpak Secret Service permission and runtime repository metadata; a verified Linux installer at `goop.dergigi.com/install.sh`; updated installation documentation.

## Checks before packaging

- 143 messaging, settings, credential, profile, and workspace library tests passed.
- 21 chat UI tests with test support passed, including two headless emoji-picker interaction tests.
- Six release-policy tests and six mocked Linux installer tests passed. Installer coverage includes both architectures, prerequisite installation, runtime ordering, version-pinned downloads, checksum rejection, and failure cleanup.
- Optimized macOS build from release commit `57f549a97292d964fcfecafe6d99f75b9a84c4d9` passed with `gpui_macos/runtime_shaders`.
- Version 2.9.0 was installed in `/Applications/Goop.app` and launched. Bundle version, strict signature, and executable-section checks passed.
- Credential implementation CI passed on Linux, macOS, and Windows. The isolated Linux D-Bus regression fixture verifies that a missing Secret portal reaches Secret Service, while an explicit portal denial does not fall back. Compatibility tests cover existing oo7 0.6 encrypted storage and account-scoped deletion.
- Landing-page build passed. The deployed short installer URL returns the repository installer byte for byte.

## Release checks

- Published [v2.9.0](https://github.com/dergigi/goop/releases/tag/v2.9.0); GitHub latest points to this version.
- [Platform CI](https://github.com/dergigi/goop/actions/runs/35078316194) passed on Linux, macOS, and Windows.
- [All six installer builds](https://github.com/dergigi/goop/actions/runs/35078318790) passed. All ten installers passed SHA-256 verification; all eleven assets matched GitHub digests and sizes. Linux ELF, Windows PE/version, Snap manifests, and both macOS bundle identities, versions, architectures, strict signatures, and camera permission descriptions passed.
- Both Flatpak bundles contain the expected runtime architecture/version, Flathub runtime repository, and Secret Service permission. Exactly one updater installer exists for each OS/architecture.
- [Homebrew update](https://github.com/dergigi/homebrew-goop/actions/runs/35080641271) passed; cask version and both macOS checksums match the verified artifacts.
- Landing-page 2.9.0 metadata build passed and commit `8d10f54` was pushed for deployment.

## Limits

macOS bundles are ad-hoc signed, not notarized; Windows installers have no developer certificate. Full interactive Windows/Linux UI testing has not been performed. The Linux credential tests use an isolated service fixture; Fiatjaf's exact environment remains unknown. The installer integration tests mock package installation and network access rather than modifying a fresh Ubuntu VM.
