# Goop 2.4.0 release validation

Application source: `v2.4.0`, commit `2f50e52de1693c61b950fe986c23fa8556ed0c73`.

## Checks

- 99 local regression tests and 6 release-tooling tests passed.
- [Cross-platform CI](https://github.com/dergigi/goop/actions/runs/34918169466) passed on macOS, Windows, and Linux.
- [Installer workflow](https://github.com/dergigi/goop/actions/runs/34918246269) passed on all six OS/architecture targets.
- All ten installers matched SHA256SUMS. All eleven uploaded assets matched GitHub's sizes and SHA-256 digests.
- Windows executable architectures and package versions, Linux tarball executable architectures and Snap versions/architectures, and both macOS bundle versions, identities, architectures, and strict signatures were verified.
- Exactly one updater installer matches each target OS/architecture.
- Published as latest stable; the public checksum download matches the validated manifest.
- An optimized local v2.4.0 build was installed and launched on Apple Silicon macOS. All executable sections match the build after bundle signing, and the installed bundle version and strict signature were verified.
- Pin regression coverage includes Amethyst DM/group/self room keys, encrypted relay round trips, preservation of unrelated settings, remote unpins, persistence, and account isolation.
- Unread regressions cover duplicate suppression, sent messages and reactions, same-second arrivals, read-position persistence, account isolation, and count clearing. Request-badge regression covers removal, viewing, ordinary chat activity, and account changes.

## Limits

Amethyst pin compatibility was checked against source and local relay fixtures; live cross-client testing remains pending. Pin settings use Nostr's last-write-wins replacement behavior. Unread positions are local to this device, use message timestamps and same-timestamp message IDs, and publish no read receipts. Existing loaded incoming history starts unread until viewed.

macOS bundles are ad-hoc signed, not notarized. Windows installers have no developer certificate. Full interactive testing of focus, tab fallback, and badge appearance on all platforms remains incomplete.
