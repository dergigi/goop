# Goop 2.8.1 release validation

## Scope

UI polish: a proper double-checkmark delivery icon, Goop feedback chat actions in Get Started and Settings, hover-only Unblock actions, purple feedback styling, and improved composer placeholders. Goop feedback routing uses the project public key rather than a display name.

## Checks before packaging

- Desktop checks and optimized local builds passed for the implementation changes.
- User visually reviewed the installed final implementation build (`3d0a932`) and approved it for release.

## Release checks

- 136 version-bumped messaging, settings, signer, profile, and workspace tests passed. Three headless dock/context-menu regressions passed.
- Six release-tooling tests passed.
- Optimized desktop build from release commit `2fda7b3e79a195ec8b6cc7570c7196a43f9267ce` passed with `gpui_macos/runtime_shaders`.
- Version 2.8.1 is installed in `/Applications/Goop.app` and running. Bundle version, strict signature, and executable-section checks passed.

- Published [v2.8.1](https://github.com/dergigi/goop/releases/tag/v2.8.1) from `2fda7b3e79a195ec8b6cc7570c7196a43f9267ce`; GitHub latest and its public checksum download match the verified release.
- [Platform CI](https://github.com/dergigi/goop/actions/runs/35026598295) passed on Linux, macOS, and Windows, including release policy and UI regressions.
- [All six installer builds](https://github.com/dergigi/goop/actions/runs/35026614287) passed. All ten installers passed SHA-256 verification, and all eleven assets matched GitHub digests and sizes. Linux ELF, Windows PE/version, Snap manifests, and both macOS bundle identities/versions/architectures/strict signatures/camera permission descriptions passed. Exactly one updater installer exists for each platform/architecture. A transient GitHub asset-download HTTP 500 cleared on retry.
- [Homebrew update](https://github.com/dergigi/homebrew-goop/actions/runs/35028437609) passed; cask version and both macOS checksums match the verified artifacts.
- Landing-page release metadata refreshed, production build passed, and commit `3f7db51` pushed for deployment.

## Limits

macOS bundles are ad-hoc signed, not notarized; Windows installers have no developer certificate. Full interactive Windows/Linux UI testing has not been performed.
