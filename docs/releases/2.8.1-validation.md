# Goop 2.8.1 release validation

## Scope

UI polish: a proper double-checkmark delivery icon, Goop feedback chat actions in Get Started and Settings, hover-only Unblock actions, purple feedback styling, and improved composer placeholders. Goop feedback routing uses the project public key rather than a display name.

## Checks before packaging

- Desktop checks and optimized local builds passed for the implementation changes.
- User visually reviewed the installed final implementation build (`3d0a932`) and approved it for release.

## Pending release checks

Version-bumped regression tests, tagged platform CI, installer builds, artifact verification, publication, Homebrew update, landing-page refresh, and local installation are pending.

## Limits

macOS bundles are ad-hoc signed, not notarized; Windows installers have no developer certificate. Full interactive Windows/Linux UI testing has not been performed.
