# Goop 2.11.2 release validation

## Scope

Preserve signer error details for sending and decryption, explain why unattempted copies are waiting, and separate delivery results from the checkmark legend. Expand installation scripts for macOS, common Linux distributions and Windows.

## Source and checks

- Release source: `cc4c11ed32c3dafc6dbbd73578760cee6e920e88` (`v2.11.2`).
- Local optimized library tests: 69 chat, 22 chat UI and 16 state tests passed.
- Six release-policy tests and 11 mocked Unix installer tests passed locally.
- [Installer CI](https://github.com/dergigi/goop/actions/runs/35230180696) passed, including 12 mocked Windows installer checks.
- Regressions verify preservation of nested signer errors, error visibility for unattempted copies, refused-send/decryption persistence across restarts, explicit retry, and delivery checkmark semantics.

## Limits

This improves diagnosis of signer refusals; Fiatjaf's original error details were discarded by the older version and cannot be recovered. His signer has not been reproduced interactively. No new external-signer or cross-client interoperability testing is claimed. Retry policy, encryption and persisted queue formats are unchanged.

Arch startup tests use software graphics under X11 and nested Wayland, not a full Omarchy desktop or hardware-GPU session. The AUR package supports x86_64.

macOS bundles are ad-hoc signed, not notarized. Windows installers are unsigned.
