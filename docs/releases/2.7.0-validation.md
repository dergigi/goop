## Scope and limits

This release adds confirmed logout, camera QR login, private user blocks and local timed mutes, report reasons and optional automatic blocking, connection diagnostics/recovery, and native Chats/Account menus. It refines profile actions/links/tabs, compact relay indicators, sidebar archives/blocked users, and the message context menu.

Blocking interoperability is checked against Amethyst source and local relay fixtures. Physical camera capture, real external-signer logout/relogin, live cross-client interoperability, and GUI flows on every platform remain unverified. The local user's real account is not logged out as a test. Local history, device encryption keys, moderation data, and the master credential are preserved by logout.

The wider UI suite has an existing scrollbar-layout expectation mismatch in `input::element::tests::test_editor_scrollbar_layout_uses_current_scroll_size`; the targeted regressions pass. No full cross-client feature-parity or performance claim is made. Camera scanning requires platform permission; sandboxed Linux packages may need camera access enabled.

macOS bundles are ad-hoc signed, not notarized; Windows installers have no developer certificate.
