# Goop 2.12.0 release validation

## Scope

Persistent text drafts and draft filters; per-message failure and retry controls; animated delivery states and recovery progress; QR-first identity pairing that survives refresh, scanner navigation and Escape; Arch launcher/icon integration.

## Source and local checks

- Release source: `3a195b7b0cb43a5475fe8fe46fce83d4f21dff49` (`v2.12.0`).
- Optimized library tests: 194 passed across chat, chat UI, common, person, settings, state, update checking and workspace. One existing test was ignored.
- Six release-policy tests and 11 mocked Unix installer tests passed.
- Pairing regressions cover authenticated approval, wrong-secret rejection, explicit cancellation, reconnectable credentials, and approval of either invitation after refreshing. Ordinary signer request deadlines retain typed timeout errors.
- The user tested the installed macOS build and reported that the tested flows work well enough to release. An alternative signer connected successfully; an Amber scanning failure was reported separately and remains unconfirmed.

## Limits

Drafts preserve composer text and reply targets, not unsent attachment files. Writes run in the background and flush on normal quit; an abrupt process or machine failure can lose the most recent pending write.

QR invitations remain active for the login session; successful approval cancels the other pending invitations. Signing and encryption requests retain a 30-second deadline. No claim of universal signer compatibility is made.

macOS bundles are ad-hoc signed, not notarized. Windows installers are unsigned. Arch startup checks use software graphics under X11 and nested Wayland rather than a full Omarchy desktop session.
