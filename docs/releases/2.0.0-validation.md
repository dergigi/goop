# Goop 2.0.0 release validation

Published [Goop 2.0.0](https://github.com/dergigi/goop/releases/tag/v2.0.0) as the latest stable release on 2026-09-14.

Application source: tag `v2.0.0`, commit `96c1a163f69b312d7bb11fcefe739db5c0ef2e5f`.

## Automated checks

- Local suites: 38 chat, 8 signer/state, 5 profile, 1 quick-search, and 6 release-policy tests passed.
- The optimized local macOS build passed with runtime shaders enabled.
- [Release-tag CI](https://github.com/dergigi/goop/actions/runs/34887766672) passed on Linux, Windows, and macOS.
- [Installer build](https://github.com/dergigi/goop/actions/runs/34887770820): the first Intel Mac attempt compiled successfully but failed to unmount cargo-packager's temporary image. The other five jobs passed. The retry passed, completing all six platform builds.

## Packaging checks

- Both Windows installers were opened as archives; their embedded executables have the expected ARM64/x64 PE architecture and their packager metadata says 2.0.0.
- Both Linux tarballs contain the expected ARM64/x64 ELF executable. Both Snap manifests report 2.0.0 and the correct architecture.
- Both Mac disk images mount successfully and contain Goop 2.0.0 with the expected ARM64/x64 architecture and existing `com.dergigi.goop` application identity. Both final bundles pass strict signature verification.
- The original Mac bundle had only a linker signature. Mac artifacts are ad-hoc signed and repackaged locally before publication; application source remains the release tag. The sealing procedure is committed as `1e90253`; `5d62a75` avoids the fragile intermediate disk-image mount in future builds.
- Developer-certificate signing and notarization are not provided. Ad-hoc bundle integrity does not establish developer identity.
- The verified Apple Silicon bundle was installed in `/Applications/Goop.app`; its signature and binary copy were checked. The previous installation is preserved at `dist/previous-install-r3noyr9c/Goop.app`. The running app was left open to preserve drafts.

- All ten original CI artifacts matched the workflow checksums. The two Mac images were then sealed and their final checksums regenerated before publishing.
- All ten final artifacts and `SHA256SUMS` matched GitHub's uploaded-asset sizes and SHA-256 digests. The public checksum download matches the local manifest.
- GitHub's latest-release endpoint resolves to stable `v2.0.0`; the updater's OS/architecture/extension filters identify exactly one asset for each of the six targets.

## Limits

These checks are compilation, regression, package-content, and installation checks.
GUI launch/upgrade smoke tests on every platform and full real-signer/cross-client
interoperability tests have not been completed. Remaining timestamp-tie history
coverage, encrypted-attachment/group interoperability, and performance work is
tracked in the [DM checklist](../research/dm-release-checklist.md). The release notes
disclose these gaps and do not claim Dark Wisp parity or complete relay history.
