# Goop 2.15.1 validation

## Scope

Restore standard mouse selection in message text and remove double-click-to-reply. Support selected-text copying via keyboard, context menu, and native Edit menu. Message transport, storage, and signer behavior are unchanged.

## Local validation

- All 41 chat UI tests passed with test-support enabled, including simulated word selection, copying, wrapped lines, dragging outside the message, link activation, and native Copy / Select All actions.
- Unicode word and paragraph selection and forward/reverse selection tests passed.
- Optimized macOS build installed locally; the user confirmed selection works and requested release.
- The subsequent native Edit menu integration passed the same test suite.
- CodeRabbit identified stale context-menu copying after keyboard focus changes. The menu now uses the visible selection; a focus-loss regression passes. CodeRabbit confirmed the fix and resolved the thread.
- Release tooling: 6 tests passed. Installer scripts: 11 tests passed. Diff whitespace check passed.

## Limits

Manual selection testing was performed on macOS. This UI fix does not establish additional messaging interoperability or platform GUI coverage. macOS remains ad-hoc signed; stable Developer ID signing is tracked in #6.
