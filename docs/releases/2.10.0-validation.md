# Goop 2.10.0 release validation

## Scope

Loaded-image gallery and profile picture previews; recent emoji and adaptive quick reactions; opt-in crash reports; Windows icon and console-window fixes; chat moderation menu actions; connection-status indicators, reconnect controls, and scrolling.

## Checks before packaging

- 152 messaging, settings, credential, profile, and workspace library tests passed; one crash subprocess fixture is intentionally ignored outside its parent test.
- Full UI suites with test support passed: 22 chat UI tests, 13 shared UI tests, and 36 workspace tests. This includes gallery keyboard navigation, short-window status scrolling, context-menu behavior, and emoji-picker interactions.
- The full UI run exposed a pre-existing scrollbar test with incorrect geometry expectations; these were corrected without changing runtime behavior. CI now runs the complete shared UI suite.
- Six release-policy tests and six mocked Linux installer tests passed.
- Optimized macOS build from the release source passed with `gpui_macos/runtime_shaders`.
- Release source: `eb5532766f123865b5dfdd08314f0f799c096dc6` (`v2.10.0`).

## Release checks

- Published [v2.10.0](https://github.com/dergigi/goop/releases/tag/v2.10.0); public latest and its checksum download resolve to this release.
- [Platform CI](https://github.com/dergigi/goop/actions/runs/35130230041) passed on Linux, macOS, and Windows, including full shared UI tests and the status-pane scrolling regression.
- [All six installer builds](https://github.com/dergigi/goop/actions/runs/35130237466) passed. All ten installers passed SHA-256 verification; all eleven assets matched GitHub digests and sizes.
- Both Windows executables have GUI subsystem type 2 and all six expected icon images; their architectures and package versions match the release.
- Both macOS bundles passed version, identity, architecture, camera permission metadata, and strict signature checks. Both Linux ELF architectures and Snap manifests match; both Flatpaks contain the correct runtime, Flathub runtime repository, and Secret Service permission.
- Exactly one updater installer exists for each OS/architecture.
- Installed Goop 2.10.0 in `/Applications/Goop.app` from the verified arm64 release disk image, preserving user data. The installed executable matches the release artifact, the signature verifies, and the app is running.
- [Homebrew update](https://github.com/dergigi/homebrew-goop/actions/runs/35132448155) passed. The cask version and both macOS checksums match the verified release.
- Landing-page production build and Vercel deployment passed for commit `bc28c32`. The live site shows 2.10.0, retains the Goop profile link, and serves the short installer URL byte for byte from the repository installer.

## Limits

macOS bundles are ad-hoc signed, not notarized; Windows installers have no developer certificate. Full interactive Windows/Linux UI testing has not been performed. Automated crash tests use isolated subprocesses and never send a real DM. Existing cross-client interoperability and large-history performance gaps in the DM validation checklist remain open; this release does not claim new protocol coverage or read receipts.
