# Goop 2.6.0 release validation

Application source: `v2.6.0`, commit `1e161ce6fdad60c387ac67285fb6bd7eefa3f183`.

## Local checks

- 96 chat, state, person, composer, and workspace tests passed, along with six release-tooling tests.
- Three GPUI regressions passed: repeated sidebar collapse/expand preserves focus in nested center tabs; oversized center contents stay within a resized viewport alongside the right dock; chat context-menu actions survive redraws. Each regression was also observed failing with its corresponding fix removed.
- The optimized release build was installed and launched on Apple Silicon macOS. Strict bundle signature verification passed, and all executable sections matched the built binary after signing.
- Release metadata, lockfile consistency, and whitespace checks passed.

## Release checks

- [Cross-platform CI](https://github.com/dergigi/goop/actions/runs/34947984853) passed on macOS, Windows, and Linux at the release commit.
- [Six-target installer workflow](https://github.com/dergigi/goop/actions/runs/34947990006) passed at the release commit.
- All ten installers matched SHA256SUMS; all eleven uploaded assets matched GitHub's recorded sizes and SHA-256 digests. Linux and Windows executable architectures, Windows/Snap package versions, and macOS bundle versions, identities, architectures, and strict signatures passed verification.
- Exactly one updater installer matches each OS/architecture.
- Published as latest stable; the public SHA256SUMS download matches the verified manifest. GitHub's authenticated latest-release API reports v2.6.0; the unauthenticated API was rate limited during verification.
- The [Homebrew update workflow](https://github.com/dergigi/homebrew-goop/actions/runs/34950070781) passed. The published cask reports 2.6.0 with both verified macOS checksums.

## Scope and limits

This release fixes sidebar focus loss affecting workspace shortcuts, profile context-menu navigation, short-window dock sizing, and portrait-avatar cropping. It aligns unread badges beside timestamps, adds release/commit links in Settings and About, and improves UI copy and the byline. It changes no messaging protocol or stored-data format.

Headless GPUI tests cover focus state, layout bounds, and actual context-menu clicks. Interactive shortcut, resize, and profile flows on every platform remain unverified. The wider UI suite has an existing scrollbar-layout expectation mismatch in `input::element::tests::test_editor_scrollbar_layout_uses_current_scroll_size`; the targeted regressions pass. Cross-client and external-signer validation limitations from previous releases remain unchanged.

macOS bundles are ad-hoc signed, not notarized; Windows installers have no developer certificate.
