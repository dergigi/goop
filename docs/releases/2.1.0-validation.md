# Goop 2.1.0 release validation

Application source: `v2.1.0`, commit `ec740672a25b366120f114415f2cb45dba79d3b6`.
The earlier unpublished candidate was cancelled and replaced before publication.

## Automated checks

- Local regression suites passed: 38 chat, 12 chat UI, 5 profile, 8 state, 7 workspace, 4 settings, and 1 theme tests; 6 release-policy tests passed.
- The optimized local macOS build passed and launched successfully.
- [CI](https://github.com/dergigi/goop/actions/runs/34897840576) passed on macOS, Windows, and Linux, including messaging and UI regressions.
- [Installer workflow](https://github.com/dergigi/goop/actions/runs/34897844651) passed for all six OS/architecture targets.

## Packaging and installation

- All ten installers matched the workflow SHA256SUMS file. All eleven uploaded assets, including the checksum manifest, matched GitHub's sizes and SHA-256 digests.
- Both Windows installers contain a Goop executable with the expected PE architecture and packager version 2.1.0.
- Both Linux tarballs contain the expected ELF architecture; both Snap manifests report version 2.1.0 and the correct architecture.
- Both Mac disk images mount, report version 2.1.0 and application identity `com.dergigi.goop`, contain the expected architecture, and pass strict bundle signature verification.
- The CI-built Apple Silicon bundle was installed at `/Applications/Goop.app` and compared with the mounted release binary. Previous installation: `dist/previous-install-xudfpfc8/Goop.app`.
- Exactly one updater asset matches each of the six target OS/architecture/installer combinations.

## Limits

macOS bundles are ad-hoc signed, not notarized. Windows installers have no developer certificate. These are regression, compilation, package-content, and installation checks; full interactive GUI checks on all platforms and real-signer/cross-client interoperability checks remain incomplete. Existing messaging coverage limitations are disclosed in the release notes.
