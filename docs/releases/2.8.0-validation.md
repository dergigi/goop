# Goop 2.8.0 release validation

## Scope

NIP-46 QR pairing with signer-neutral UI, cancellation, expiry, retry, and a saved bunker connection. Removes experimental NIP-4e/device key sharing, browser-extension login, the web build, and the unused upstream public-key constant. Existing keys and chat data are preserved.

## Checks before packaging

- User confirmed successful pairing with Amber on the local build.
- Four local-relay pairing tests passed, including QR decoding, wrong-secret rejection, cancellation, expiry, distinct signer/account identities, and reconnect. Five consecutive runs passed after allowing the test signer subscription to settle.
- 47 state/workspace tests passed before the version bump. Desktop check and optimized build passed.
- Cross-platform Rust CI passed for the final implementation commit `8d29fdbf99fc39a355382924ca1210ebcd2bc748`.
- Six release-tooling tests passed.

## Release checks

- 136 version-bumped messaging, settings, signer, profile, and workspace tests passed. Three headless dock/context-menu regressions passed.
- The optimized desktop build from release commit `a0f82bf4c4379039914b321b670b3f5d9fc620ca` passed with `gpui_macos/runtime_shaders`.
- Version 2.8.0 is installed in `/Applications/Goop.app` and running. Bundle version, strict signature, and executable-section checks passed.
- An initial local linker failure was caused by disk exhaustion. Removing generated incremental build cache freed space; the complete local test run then passed.

- Published [v2.8.0](https://github.com/dergigi/goop/releases/tag/v2.8.0) from `a0f82bf4c4379039914b321b670b3f5d9fc620ca`; GitHub latest and its public checksum download match the verified release.
- [Platform CI](https://github.com/dergigi/goop/actions/runs/35014720789) passed on Linux, macOS, and Windows, including release policy and UI regressions.
- [All six installer builds](https://github.com/dergigi/goop/actions/runs/35014730272) passed. All ten installers passed SHA-256 verification; all eleven assets matched GitHub digests and sizes. Linux ELF, Windows PE/version, Snap manifests, and both macOS bundle identities/versions/architectures/strict signatures/camera permission descriptions passed. Exactly one updater installer exists for each platform/architecture.
- [Homebrew update](https://github.com/dergigi/homebrew-goop/actions/runs/35016837782) passed; published cask version and both macOS checksums match the verified artifacts.
- Landing-page release metadata refreshed, production build passed, and commit `5921ecf` pushed for deployment.

## Limits

Amber pairing is user-verified; other signers and full interactive UI flows on Windows/Linux have not been manually verified. macOS bundles are ad-hoc signed, not notarized; Windows installers have no developer certificate.
