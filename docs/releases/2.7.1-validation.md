## Scope and limits

This patch aligns blocked-user rows, collapses optional report explanations, replaces report completion dialogs with toasts, shows connected relay counts, and renders history relays compactly. It makes signer setup reachable without a profile menu and surfaces startup credential failures with a retry action.

Fiatjaf's Windows screenshot shows an unavailable signer without a profile menu. The exact credential-store failure was not reproduced on Windows. The new setup/recovery path is implemented, but real Windows first-run and external-signer login still need user verification. No live account was logged out, blocked, or reported for testing. No physical-camera or full desktop GUI interaction test was performed.

macOS bundles remain ad-hoc signed, not notarized; Windows installers have no developer certificate.
