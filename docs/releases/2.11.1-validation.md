# Goop 2.11.1 release validation

## Scope

Replace the in-app installer with release notifications. Check after the window opens and every six hours; show a release link in the title bar for all installation methods. Add an Arch/AUR package and remove Homebrew's self-updating flag.

## Source and local checks

- Release source: `907e09be4b68682945e607e5830b102f4cc66547` (`v2.11.1`).
- 180 local library regression tests passed; one crash subprocess fixture is intentionally ignored outside its parent test.
- Six release-policy tests and six mocked Linux installer tests passed.
- Release-check tests cover numeric version ordering, equal/older versions, build metadata, drafts, prereleases, malformed responses, and release links.
- The preceding development build compiled and was installed locally. It was not a published release build.
- Removed `gpui-updater` and its unused dependencies. Release checks only request GitHub metadata and cannot download or install an app update.

## Limits

The AUR package currently targets x86_64. Arch startup checks use software rendering under Xvfb and nested Weston; they are not a full Omarchy session or a real-signer test. Existing cross-client and hardware-GPU coverage gaps remain.

macOS bundles are ad-hoc signed, not notarized; Windows installers have no developer certificate.
