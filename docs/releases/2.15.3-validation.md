# Goop 2.15.3 validation

## Scope

Limit simultaneous LMDB reads to 16 across all read methods. Requests above that limit wait asynchronously. Keep the permit until the underlying operation finishes when its caller cancels. Writes remain independent of the read limit. No database schema changes or dependency upgrades.

## Local validation

- All 24 state tests passed.
- A 512-operation burst respected a four-reader test budget and completed all work.
- Cancelling a caller retained the occupied slot until the operation finished; errors released slots and subsequent reads succeeded.
- 256 mixed reads passed against real LMDB configured with only two reader slots and a one-reader operation budget. Save, delete, and wipe operations also passed.
- Release-tool tests: 6 passed. Installer-script tests: 11 passed. Diff whitespace check passed.

## Limits

The original user's trigger is unknown. Tests cover the identified unbounded-read path, not a reproduction of their session. No additional real external-signer or cross-client interoperability claim is made. This change does not repair an unrelated corrupt database or alter stored messages. macOS remains ad-hoc signed; stable Developer ID signing is tracked in #6.
