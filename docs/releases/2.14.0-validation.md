# Goop 2.14.0 release validation

## Changes

- Cmd/Ctrl+L focuses the composer, with a subtle hint while it is unfocused. Cmd/Ctrl+3 remains an alias.
- Cmd+Option+Up/Down on macOS and Ctrl+Alt+Up/Down elsewhere browse loaded sent text in the current conversation.
- Browsing preserves the original saved/synced draft. Moving past the newest entry restores it, or clears an originally empty composer.
- Standard cursor navigation and selection shortcuts are unchanged.

## Source validation

- Optimized macOS desktop build passed with runtime shaders.
- Chat UI and workspace library tests passed: 33 and 39 tests, respectively.
- New regression checks cover history boundaries, multiline entries, returning to an empty/nonempty original draft, and exact modifier matching without claiming normal movement or selection shortcuts.
- Release policy tests: 6 passed. Mocked Unix installer tests: 11 passed.
- Source feature commit: 1706abc. Release commit: bbee858. Tag: v2.14.0.

## Limits

- History recall uses loaded sent text, not attachment re-uploading or a server-side full-history search.
- No new interactive external-signer or cross-client draft-sync test was performed for these composer changes.
- macOS remains ad-hoc signed; update-time Keychain prompts remain a known limitation tracked in #6.
