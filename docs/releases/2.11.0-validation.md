# Goop 2.11.0 release validation

## Scope

Bot/person chat filters and self-declared bot profile information, background avatar thumbnails, report-dialog polish, and gallery downloads and viewport fitting.

## Checks before packaging

- 199 local library and UI regression tests passed; one crash subprocess fixture is intentionally ignored outside its parent test.
- Six release-policy tests and six mocked Linux installer tests passed.
- Optimized macOS build from the release source passed with `gpui_macos/runtime_shaders`.
- Avatar tests cover filtering high-frequency image detail, centered cropping, transparency, animation timing, memory-limited animation thumbnails, shared requests, negative caching, and retries.
- Gallery tests cover image navigation, original-image download eligibility and filename selection, and very wide/tall images remaining inside the window after resizing.
- Settings tests verify old hide-avatar values are ignored and other preferences remain intact. Existing messaging, local-state persistence, and reaction regressions passed.
- User testing confirmed the preceding local avatar-thumbnail build works well.
- Release source: `79b58a774e0199ba32a64b35f4ea9bd6fd4cd12d` (`v2.11.0`).

## Release checks

- Published [v2.11.0](https://github.com/dergigi/goop/releases/tag/v2.11.0) on 2026-09-17 at 09:17:56 UTC. Public latest and its checksum download resolve to this release.
- [Platform CI](https://github.com/dergigi/goop/actions/runs/35202259951) passed on Linux, macOS, and Windows, including the new cache and gallery UI regressions and Linux credential fallback checks.
- [All six installer builds](https://github.com/dergigi/goop/actions/runs/35202263219) passed. All ten installers passed SHA-256 verification; all eleven assets matched GitHub digests and sizes.
- Both Windows executables have GUI subsystem type 2 and all six icon images. Their architectures and package versions match the release.
- Both macOS bundles passed version, identity, architecture, camera permission metadata, and strict signature checks. Linux ELF architectures and Snap manifests match; both Flatpaks contain the expected runtime, Flathub runtime repository, and Secret Service permission.
- Exactly one updater installer exists for each OS/architecture.
- Installed and opened the Apple Silicon build in `/Applications/Goop.app`, preserving user data. The workflow disk image used for installation matches the published artifact digest, and the installed executable matches its verified release bundle.
- [Homebrew update](https://github.com/dergigi/homebrew-goop/actions/runs/35204352109) passed; the cask version and both macOS checksums match the published release.
- Landing-page production build and Vercel deployment passed for commit `bf0eb5b`. The live site shows 2.11.0, includes all release asset links and the Goop profile link, and serves `install.sh` byte for byte from the repository installer.

## Limits

The 32 MiB avatar budget covers cached thumbnails, not total application memory or temporary decoding buffers. Up to two avatar jobs run concurrently. Thumbnails whose animation would exceed 8 MiB use a still frame; the gallery retains original images. Avatar thumbnails are held in memory and are regenerated after restart or eviction.

macOS bundles are ad-hoc signed, not notarized; Windows installers have no developer certificate. Full interactive Windows/Linux UI testing and real-signer/cross-client interoperability testing have not been performed for this release. Existing coverage gaps in the DM validation checklist remain open.
