# Goop 2.2.0 release validation

Application source: `v2.2.0`, commit `e69928c621bb38a061e179c1bb145a5fb1f3f66d`.
An initial unpublished tag was corrected to use the UTC release date before building.

## Checks

- 86 local regression tests and 6 release-tooling tests passed.
- [Cross-platform CI](https://github.com/dergigi/goop/actions/runs/34909899740) passed on macOS, Windows, and Linux.
- [Installer workflow](https://github.com/dergigi/goop/actions/runs/34909899980) passed on all six OS/architecture targets.
- All ten installers matched SHA256SUMS. All eleven uploaded assets matched GitHub's sizes and SHA-256 digests.
- Windows executable architectures and package versions, Linux tarball executable architectures and Snap versions/architectures, and both macOS bundle versions, identities, architectures, and strict signatures were verified.
- Exactly one updater installer matches each target OS/architecture.
- Published as latest stable; the public checksum download matches the validated manifest.
- The user confirmed an encrypted image upload to their whitelisted Haven server succeeds with the preceding local build of these application changes.

## Limits

Dark Wisp compatibility was checked against source and regression fixtures; live cross-client tests remain pending. macOS bundles are ad-hoc signed, not notarized. Windows installers have no developer certificate. Full interactive testing on all platforms remains incomplete.
