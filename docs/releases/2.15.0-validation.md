# Goop 2.15.0 validation

## Scope

Local multilingual dictation with Parakeet v3. PR #13, merged after user testing and review.

## Before tagging

- Source CI passed on Linux, macOS, and Windows for final feature commit e6890a6 (runs 37914055774 and 37914049417).
- 81 deterministic tests passed across speech, chat_ui, and workspace.
- Actual INT8 model transcribed English, German, Portuguese, silence, and a 38.45-second recording. Full archive installation and hash verification passed.
- User tested the optimized macOS build and final Cmd+D / Enter / Escape flow, then requested release on 2026-10-09.
- Release tooling tests: 6 passed. Installer script tests: 11 passed.
- CodeRabbit's single finding concerned a supposed total download timeout. Inspection of resolved reqwest 0.12.28 and a local HTTP streaming probe confirmed that blocking Response::read resets the timeout each read. The production 15-second setting successfully read a 17.10-second transfer. Finding answered with evidence on PR #13; no code change needed.

## Limits

Actual microphone capture and permissions were manually tested on macOS. Windows, Linux, and Flatpak microphone behavior still needs manual coverage. Earlier automated remote downloads were blocked while Rust networking timed out; the local archive test and subsequent user app test are recorded separately. No new broad messaging interoperability claim is made by this release.
