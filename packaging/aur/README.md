# goop-bin

The AUR package installs the published x86_64 Linux binary with Arch's system libraries. It includes the desktop launcher, icons, and `nostr:`/`goop:` URL handlers. It does not compile Goop.

A Secret Service provider must be available and unlocked to save signer credentials. The package lists GNOME Keyring and KWallet as optional providers because users may already have another provider.

The launcher disables the automatic updater in Goop 2.11.0 and earlier. Newer releases only display release notices. Updates belong to the AUR helper and pacman.

## Updating a release

1. Publish and verify the Goop release first. AUR sources must be publicly downloadable.
2. Update `pkgver`, reset `pkgrel` to 1, and set the tarball SHA-256 from the verified release. Update the launcher checksum if its contents changed.
3. Push the recipe to the Goop repository. The **AUR package** workflow builds and installs it on Arch, checks runtime dependencies and desktop metadata, and launches it under X11 and Wayland with software graphics.
4. Download the successful workflow's `aur-package` artifact. It contains the `.SRCINFO` generated by `makepkg --printsrcinfo`.
5. Copy `PKGBUILD`, `goop`, and `.SRCINFO` into the `ssh://aur@aur.archlinux.org/goop-bin.git` checkout. Commit and push to its `master` branch using the dedicated AUR SSH key.
6. Verify the package version through AUR's public API.

Keep private keys out of this directory and Git. The AUR repository contains only `PKGBUILD`, `.SRCINFO`, and the launcher.
